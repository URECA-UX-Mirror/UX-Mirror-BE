# 결과 폴더 안내

```
results\
├ run_log.md        모든 실행 한 줄 요약
├ json\             데이터 (Git에 올림)
│  ├ a\             A 묶음: a_<시각>.jsonl
│  ├ b5\            B5: b5_<시각>.jsonl (화면별 요청·응답·확률)
│  ├ candidates\    후보·도착 판정: candidates_<시각>\<variant>_<page>.json
│  └ _archive\      중간 확인용 (지워도 됨)
└ screenshots\      사진 (Git에 안 올림)
   ├ b5\            b5_<시각>\<variant>_<page>.png (확률 배지)
   ├ candidates\    candidates_<시각>\<variant>_<page>.png (후보 번호 박스)
   └ _archive\
```

json과 사진은 같은 이름(`<시각>`, `<variant>_<page>`)으로 짝이 맞는다.
새 실행부터는 json에 `"screenshot": "screenshots/..."` 경로가 들어간다.
